# Exploracion_de_datos_multivariados
Proyecto que se realizo durante el semestre en el cual se propone un dataset y se debe de limpiar, explorar y ejecutar un analisis estadistico descriptivo y luego uno Inferencial aplicando test estadisticos provistos por la catedra y defendiendolo en un informe final que exponga como fue el proceso y a que conclusiones se llega respecto a los datos.
